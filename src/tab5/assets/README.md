# Tab5 text assets

Embedded into the Tab5 firmware (`board_build.embed_files` in `platformio.ini`)
so the UI can draw text beyond ASCII and colour emoji. Generated by
`tools/make_tab5_text_assets.py`; see its header for the sources and the
`emoji26.bin` layout.

| File | What | Source | Licence |
|---|---|---|---|
| `text.ttf` | Latin-1, Latin Extended, Cyrillic, punctuation | Montserrat Medium (subset) | SIL OFL 1.1, `OFL-Montserrat.txt` |
| `more.ttf` | Greek, Vietnamese, Armenian, Georgian, arrows, maths | Noto Sans Medium (subset) | SIL OFL 1.1, `OFL-NotoSans.txt` |
| `emoji26.bin` | 1393 emoji as 26 px PNGs | Noto Color Emoji | SIL OFL 1.1, `OFL-NotoColorEmoji.txt` |
